# v0.7 Safe AI Agent

## 目标

v0.7 不绑定具体大模型，而是先建立统一的 Agent → Plan → EditIntent → Verify → Rollback 协议。任意 LLM 后续只需要实现 `AgentProvider`。

```text
User prompt
  ↓
AgentProvider
  ↓
AgentPlan
  ↓
EditIntent
  ↓
Snapshot
  ↓
Patch
  ↓
typecheck / build
  ↓
Accept or Rollback
```

## MVP Provider

当前提供 `heuristic-local`，仅支持可证明安全的：

- Ant Design Vue `a-button` 的静态 `type` 修改
- `a-input` / `input` / `textarea` 的静态 `placeholder` 修改
- 单层直接文本修改

它不是通用 AI，仅用于验证 Agent Kernel 的事务闭环。

## 安全规则

- 必须存在唯一 Source Candidate
- `ambiguous` / `lost` 不允许自动计划
- 目标源码片段重复出现时拒绝 `replace-text`
- Plan 默认需要人工确认
- Apply 前自动 Snapshot
- typecheck/build 失败自动 Restore
