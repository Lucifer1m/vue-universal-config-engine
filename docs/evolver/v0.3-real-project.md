# v0.3 Real Project Evolution

## Goal

把一个真实 Vue3 + Vite + TypeScript 工程接入高代码演化器，完成：

```text
scan → inspect → capabilities → plan → safe evolve → reparse → verify → history → rollback
```

## v0.3 关键实现

### 1. Project Index

每次扫描生成页面、组件、import、state、诊断摘要，供平台或未来 IDE 使用。

### 2. Local Component Resolver

对 `./Foo.vue`、`@/components/Foo.vue` 等常见 local import 做解析；解析失败不会影响父页面分析，未知组件仍可作为 BlackBox。

### 3. Safety Classification

```text
SAFE       set-prop / remove-prop / set-binding / set-event / set-text
ASSISTED   insert-child / delete-node
RISKY      set-visibility
REJECTED   未知语义
```

### 4. Transaction

一轮多文件演化先验证 source hash，再逐文件执行 Patch；任何重解析/严格验证失败都恢复本轮已经修改的文件。

### 5. Journal

`.hcbridge/history/ev_xxx.json` 保存：

- 演化 ID
- 文件前后 hash
- diff
- inverse patch
- verification
- safety summary

## 验收方式

选择一个真实的列表页：

1. `scan` 发现页面。
2. `capabilities` 找到 Button/Input/Table。
3. 选择一个稳定 nodeId。
4. 修改静态属性和简单绑定。
5. `evolve --dry-run` 检查计划。
6. 正式执行 `evolve`。
7. 检查 Git diff 只改变目标范围。
8. `verify` 通过。
9. `history` 出现 journal。
10. `rollback` 后源码恢复到演化前 hash。

## 明确不做

- 不将整页生成成新的 JSON 页面运行时。
- 不在这一阶段实现三方 Merge。
- 不假装支持任意 Vue 语义。
- 不对动态组件、JSX、复杂 composable、DOM hack 强制结构化。
