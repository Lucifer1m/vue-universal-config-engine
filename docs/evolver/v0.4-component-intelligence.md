# v0.4 Component & Capability Intelligence

## 目标

把“组件实例识别”提升为“组件契约 + 本地依赖图”。任何可解析的本地 Vue 组件都至少暴露：props、emits、models、slots、exposes 和 import edges。

## 边界

v0.4 不修改现有业务源码，不做复杂 JS 语义推断，不承诺自动理解第三方黑盒组件。它增强的是分析能力和配置前置数据。

## CLI

```bash
pnpm run cli -- contract fixtures/local/UserSelector.vue
pnpm run cli -- graph fixtures/local/Parent.vue
```

## 契约来源

- `defineProps<T>()`
- `defineProps({ ... })`
- `withDefaults(defineProps<T>(), ...)` 中的 props 类型继续按 `defineProps` 处理
- `defineEmits([...])`
- `defineEmits<T>()` 的 property/method/call signature
- `defineModel()`
- `defineExpose({ ... })`
- `<slot name="...">`
- `defineOptions({ name: ... })`

## 安全策略

提取不到类型时使用 `unknown`，不猜测；本地递归遇到深度、文件数或循环边界时记录 diagnostic。
